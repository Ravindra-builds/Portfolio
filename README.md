# Ravindra Yadav — Modern Portfolio

Personal portfolio site for **Ravindra Yadav**, AI & Full-Stack Developer — built with Next.js 16, React 19, and Tailwind CSS v4.

**Live:** [ravindrayadav.online](https://www.ravindrayadav.online)

---

## Overview

A modern, high-performance portfolio showcasing production full-stack systems and GenAI/AI work — RAG architectures, multi-LLM platforms, autonomous agents, and real-time distributed applications. Features an interactive orbital skills visualization, a developer command palette (`Cmd + K`), scroll-triggered animations, project category filters, and seamless light/dark theming.

## Tech Stack

- **Framework:** Next.js 16 (App Router with Turbopack)
- **Language:** TypeScript
- **UI:** React 19, Tailwind CSS v4
- **Components:** shadcn/ui, Radix primitives, Lucide React
- **Theming:** `next-themes` (system-aware light/dark mode)
- **Icons:** `lucide-react`, `react-icons`
- **Fonts:** Geist & Geist Mono
- **Deployment:** Vercel

## Key Modernizations & Features

- 🌗 **Light & Dark Mode Consistency** — System-aware, persisted, with fully token-based color styling across every section and interactive component.
- ⌨️ **Developer Command Palette (`Cmd + K` / `Ctrl + K`)** — Quick keyboard-driven navigation, theme toggling, resume downloading, and instant email copy.
- 📈 **Real-Time Scroll Progress Indicator** — Ultra-smooth reading progress bar seamlessly integrated along the top navbar rim.
- 🪐 **Orbital Skills Visualization** — A two-ring animated orbit (core stack + AI/GenAI) built with pure CSS keyframes and hover-responsive pause states.
- 📇 **Interactive Project Filtering & Architecture Badges** — Filter projects by category (`All`, `AI & GenAI`, `Full-Stack`, `Real-Time`), complete with live demo links, architecture tags, and repository links.
- 🧭 **Journey & Milestones Timeline** — Visual career roadmap from core Computer Science fundamentals to building autonomous AI agents and high-concurrency systems.
- 📋 **1-Click Copy Email & Instant Toast** — Quick clipboard actions with visual checkmarks and feedback across Hero, Contact, and Command Palette.
- ✍️ **Technical Writing Highlights** — Curated engineering breakdowns from [Hashnode](https://rvindra.hashnode.dev).
- 🕒 **Auto Last-Updated Footer** — Reads the latest git commit at build time, eliminating manual date bumps.
- 🔍 **SEO & Structured Data Ready** — Person and WebSite JSON-LD schemas, canonical URLs, sitemap, robots.txt, and PWA manifest.

## Getting Started

```bash
# install dependencies
npm install

# run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm start       # run production build locally
npm run lint    # eslint
```
